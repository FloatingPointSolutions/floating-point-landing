what we do.

software

we design, build and run software for companies of any size, from a first product to the systems a whole operation depends on.

  • web and mobile applications
  • internal platforms and back-office tools
  • integrations and apis
  • data pipelines and reporting

cybersecurity

we find the weaknesses before someone else does, fix them, and keep watch afterwards.

  • security assessments and risk management
  • hardening and compliance (iso 27001, nis2, gdpr)
  • monitoring and threat detection
  • incident response
  • secure development and code review
  • security training for teams
